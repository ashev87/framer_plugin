## 2. r/SideProject

**Title:** I checked a few dozen startup careers pages. Many still list jobs that closed weeks ago.

> I'm building SyncRoles, a plugin that keeps a careers page built in Framer in sync with the company's hiring tool (Ashby, Greenhouse, Lever, Personio).
>
> While looking for first customers I kept seeing the same thing: careers pages that link to job postings which are already closed, and open roles that never made it onto the page. Most of these pages are updated by hand, so they drift.
>
> So I turned the check I was doing by hand into a free tool: paste a careers page, and it compares every job link on the page with the public job board and lists what's out of date. No sign-up.
>
> syncroles.com/check
>
> It works on any website builder, not just Framer, as long as the page links to the individual job postings. If your roles load in a script widget it can't see them yet.
>
> First paying customer came in on day 5, from someone who googled "auto sync ashby framer". I'm building this for a 30-day hackathon, so feedback on the checker is very welcome: what would make you trust the result?
