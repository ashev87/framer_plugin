Why not the free Greenhouse import?

The free Greenhouse plugins for Framer import roles when someone opens the plugin and clicks. Nothing changes on your site between those clicks, so closed roles stay up. SyncRoles runs on its own server, so your careers page follows Greenhouse by itself.

Setup takes three steps

  • 01

    Enter your Greenhouse board

    Open the plugin, pick Greenhouse and type your company name from boards.greenhouse.io/your-company. You see the roles it found before anything is written.

  • 02

    Connect the project

    Paste your Framer project address and a Server API key (Site Settings > General). SyncRoles creates a Jobs collection.

  • 03

    Bind your page once

    Point the careers list and job page at the Jobs collection. From then on the content follows Greenhouse.

Fields you get from Greenhouse

    • Title
    • Department
    • Location
    • Employment Type
    • Remote
    • Description
    • Job URL
    • Apply URL
    • Published At

Greenhouse has no standard employment-type field, so that field stays empty unless your company added one. Greenhouse shows its application form on the job page, so Apply URL and Job URL are the same link.

You decide what gets published

Publishing in Framer publishes the whole project, so SyncRoles never publishes on its own unless you choose it. See the three publishing modes.

Questions

Does it keep syncing Greenhouse jobs when Framer is closed?

Yes. On a paid plan the sync runs on the SyncRoles server every 15 minutes. Nobody needs to have Framer or the plugin open. On the free plan you start each sync yourself from the plugin.

Do I need a Greenhouse API key?

No. SyncRoles reads your public Greenhouse job board, for example boards.greenhouse.io/your-company. Applications go straight to Greenhouse through its own apply links.

Can it publish my unfinished design work?

Only if you choose “Always publish”. The default is that SyncRoles never publishes. With “Publish when only jobs changed”, it checks with Framer before each sync and skips publishing if any page has other unpublished changes.

What does it cost?

Manual sync from the plugin is free. Automatic sync is $99 per site per year, or $249 per year for up to five sites, plus tax where it applies.
