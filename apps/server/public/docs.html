Setup guide

About five minutes, once per Framer project.

1. Find your company handle

  • Lever: the last part of jobs.lever.co/your-handle. Tick "hosted in the EU" if your board is on jobs.eu.lever.co.
  • Greenhouse: the last part of boards.greenhouse.io/your-handle.
  • Ashby: the last part of jobs.ashbyhq.com/your-handle.
  • Personio: the first part of your-handle.jobs.personio.de. The XML feed must be switched on in Personio under Settings › Recruiting › Career page.

2. Create a Framer Server API key

  1. Open your project in Framer and go to Site Settings › General.
  2. Under API keys, create a new key and copy it.

The key belongs to this one project. SyncRoles stores it encrypted and you can delete it from the plugin at any time, which stops all syncing.

3. Connect in the plugin

  1. Open SyncRoles from the Framer Marketplace in your project, choose your hiring tool, enter the handle and click Find jobs.
  2. Paste your project URL (the address in your browser while the project is open) and the API key.
  3. Choose how publishing should work, then click Create Jobs collection and sync.

SyncRoles creates a CMS collection called Jobs with title, department, team, location, employment type, remote, compensation (when the job board shows it), description, job page link, apply link and publish date. The field names match Framer's own Ashby plugin, so a page built on that collection maps across with the same headers. Build your careers page from it like any other CMS collection.

Publishing

Publishing in Framer always publishes the whole project. That is why you choose:

  • I publish myself: jobs are updated in the CMS and go live the next time you publish.
  • Publish when only jobs changed: SyncRoles publishes after a sync, unless the project already had unpublished page changes.
  • Always publish: publishes after every sync that changed something, including any unfinished design work.

Webflow

  1. Go to syncroles.com/webflow and click Connect your Webflow site. Webflow asks you to choose the sites SyncRoles may access. It requests access to your sites list and CMS only.
  2. Choose the site, your hiring tool and your job-board name (the same handle as above), and click Find jobs.
  3. Choose how publishing should work, then click Create collection and sync. SyncRoles creates a Jobs collection with the same fields as for Framer, plus Source ID and Sync Hash, which it uses to track each job. Do not edit those two.
  4. In the Designer, build your careers list and the Jobs template page from the collection, then publish the site once.
  5. To sync every 15 minutes, paste your licence key on the same page. That page is also where you sync by hand, change the publishing mode or disconnect.

The site needs a Webflow site plan with CMS. With Publish the jobs, SyncRoles publishes the job items one by one, so other unpublished changes on your site stay unpublished. If the site has never been published, the jobs are saved without publishing until you publish the site once.

The management page remembers your site in this browser. To manage it from another browser, click Connect your Webflow site again and set it up once more. The site keeps its licence.

If something goes wrong

If your job board cannot be reached or suddenly returns no jobs at all, SyncRoles changes nothing and records the failure in the run log inside the plugin. Questions: info@smartprocesslab.de.
