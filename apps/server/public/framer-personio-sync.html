Why not the free Personio import?

The free Personio plugins for Framer import roles when someone opens the plugin and clicks. Between clicks, new roles are missing and closed roles stay up. SyncRoles runs on its own server, so your careers page follows Personio by itself.

Setup takes three steps

  • 01

    Enter your Personio board

    Open the plugin, pick Personio and type your company name from your-company.jobs.personio.de. You see the roles it found before anything is written.

  • 02

    Connect the project

    Paste your Framer project address and a Server API key (Site Settings > General). SyncRoles creates a Jobs collection.

  • 03

    Bind your page once

    Point the careers list and job page at the Jobs collection. From then on the content follows Personio.

Switch on the XML feed in Personio's career page settings first; SyncRoles reads that feed.

You decide what gets published

Publishing in Framer publishes the whole project, so SyncRoles never publishes on its own unless you choose it. See the three publishing modes.

Questions

Does it keep syncing Personio jobs when Framer is closed?

Yes. On a paid plan the sync runs on the SyncRoles server every 15 minutes. Nobody needs to have Framer or the plugin open. On the free plan you start each sync yourself from the plugin.

Do I need a Personio API key?

No. SyncRoles reads your public Personio job board, for example your-company.jobs.personio.de. Applications go straight to Personio through its own apply links.

Can it publish my unfinished design work?

Only if you choose “Always publish”. The default is that SyncRoles never publishes. With “Publish when only jobs changed”, it checks with Framer before each sync and skips publishing if any page has other unpublished changes.

What does it cost?

Manual sync from the plugin is free. Automatic sync is $99 per site per year, or $249 per year for up to five sites, plus tax where it applies.
